1. 新增代码（src/vgx/quantum_katas/）
  load.py           固定 commit 文件哈希校验；按 task_id 加载 28 题（entry_point 有重名）；
                    PublicTask 不含 canonical_solution/test；从上游 prompt 解析全部必需函数
                    （MagicSquareGame/2.6 同时要求 alice_quantum、bob_quantum）。
  prompt.py         generator 返回 {"code","p_correct"}，verifier 返回 {"p_correct"}；
                    prompt_version=qkatas_official_v1_json_or_single_fence：整段 JSON，或整段恰好
                    一个 ```json/``` fence；完整 JSON 解析，拒绝重复键、NaN/Infinity、布尔、越界、
                    多余字段；provider 声明截断即格式失败；不修复、不补问。
  artifacts.py      FrozenCodeCandidate（task_id、generation_id、candidate_id、raw_code、code_sha256、
                    raw_p_correct、各状态、模型身份、request_key、execution_id、prompt/response 哈希、
                    prompt_version、dataset_revision）；身份由来源和代码哈希决定，写入后不可改；
                    verifier 只看白名单视图（题面、入口、必需函数、代码）。
  runners.py        复用 VertexBatchRunner / VertexPartnerRunner 与 execute_request；Claude adaptive
                    thinking 走独立的 AnthropicVertexRunner（参数原样进入身份与请求体）；离线 MockRunner。
  oracle_worker.py  独立解释器中的纯标准库 worker，原样调用官方 evaluate_solution(code, test,
                    entry_point, timeout=30.0)，返回全部官方字段，另记执行代码哈希与环境。
  oracle.py         每个冻结候选一次评估：先写 intent，再写 result 或 service_error；intent 无结果
                    或服务错误均为 unresolved，永不重跑；外层 supervisor 超时记服务异常，不冒充官方
                    Timeout；key 绑定 task、candidate、code、test、evaluator 与环境哈希。
                    后端：reviewed_local（只运行已审阅 fixture 白名单）、macos_sandbox
                    （sandbox-exec 禁网、禁读主目录与仓库、只能写作业目录、清空环境变量、CPU/文件
                    rlimit；未审阅的模型代码还需 model_code_execution_approved=true）、mock。
  run_pilot.py      sealed plan.json；collect-generators / collect-verifiers 只读公开文件与缓存，
                    默认禁 API；真实 provider 需要 --allow-api、budget 与 paid_collection_authorized；
                    BudgetedRequestCache 记账，不确定请求不重发；score-official 只在私有侧运行。
  sequential.py     复用 NestedPlanner 与 seal/unseal；策略选中某层才请求该层信号；无代码或
                    r 无效直接弃答（不填 0.5）；checkpoint 恢复不重复请求；replay 只读被选层。
  report.py / workflow.py / dryrun.py   报告、CLI、离线 dry-run fixtures。
GPQA、common 模块均未修改；GPQA 缓存身份不变。

2. 可运行命令（主环境 .venv；量子执行自动使用独立解释器）
  离线 dry run（sandbox 后端，约 30 秒）：
    PYTHONPATH=src .venv/bin/python -m vgx.quantum_katas.workflow dry-run \
      --root results/quantum_katas_official_dryrun_<id> --checker macos_sandbox
  真实 pilot（模型与预算确认、填好配置之后）：
    W="PYTHONPATH=src .venv/bin/python -m vgx.quantum_katas.workflow"
    $W prepare --config configs/quantum_katas_official_pilot_<run_id>.json \
               --output results/quantum_katas_official_pilot_<run_id>
    $W collect-generators --root R --allow-api --limit 3     # 前三题冒烟
    $W collect-verifiers  --root R --allow-api --limit 3
    $W score-official     --root R --limit 3
    （检查格式、身份、计费、冻结、隔离均正常后去掉 --limit 继续其余 25 题）
    $W synthetic-policy --root R --output R/../policy_synthetic.json
    $W run-sequential --root R --policy R/../policy_synthetic.json
    $W report --root R
  测试：.venv/bin/python -m pytest tests/test_quantum_katas_*.py
